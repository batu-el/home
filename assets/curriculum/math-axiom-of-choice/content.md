*based on* the [axiom of choice](https://en.wikipedia.org/wiki/Axiom_of_choice).

Suppose we have a collection of nonempty sets, possibly infinitely many of them, and we want to pick one element from each. For finitely many sets, we walk down the list and point at an element in each. For infinitely many sets, we are fine if every set comes with a built-in rule for picking (the smallest natural number, the leftmost point, the lexicographically first sequence). But if we have infinitely many sets that are arbitrary, with no canonical structure to lean on, then it is unclear how one would pick one element from each. There is no rule to invoke and no procedure to run. 

The *[axiom of choice](https://en.wikipedia.org/wiki/Axiom_of_choice)* is the axiom that states a simultaneous selection exists anyway. For any collection of nonempty sets, there is a function $f$ that sends each set $S$ to some element $f(S) \in S$. The axiom does not tell you what that function is. It only promises that one is there.

The axiom is independent of the other [Zermelo–Fraenkel axioms](https://en.wikipedia.org/wiki/Zermelo%E2%80%93Fraenkel_set_theory) and has interesting properties. [Gödel](https://en.wikipedia.org/wiki/Kurt_G%C3%B6del) showed it cannot be disproved, [Cohen](https://en.wikipedia.org/wiki/Paul_Cohen) showed it cannot be proved, so accepting or rejecting it is a choice in its own right. If we accept the axiom, every set can be [well-ordered](https://en.wikipedia.org/wiki/Well-ordering_theorem), every vector space has a [basis](https://en.wikipedia.org/wiki/Basis_(linear_algebra)), and [Zorn's lemma](https://en.wikipedia.org/wiki/Zorn%27s_lemma) holds. But the axiom also implies counterintuitive results, such as the *[Banach–Tarski paradox](https://en.wikipedia.org/wiki/Banach%E2%80%93Tarski_paradox)*: a solid ball can be cut into finitely many pieces and reassembled into two balls of the same size. The choice function is a well-ordering of the reals, which is the [non-measurable set](https://en.wikipedia.org/wiki/Non-measurable_set) used to slice the ball.
